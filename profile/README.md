## Nosso GitHub
Nosso github esta estruturado por projetos, os quais podem ser acessador pela lista acima, cada projeto deve ter sua tag própia para facilitar o reconhecimento. Também temos times para facilitar a identificação dos membros, você pode acessar via a aba no topo da página e pedir acesso ao seu time, no momento temos os seguintes times:

 - [Eletrônica](https://github.com/orgs/AntaresOrg/teams/eletronica)
 - [Estrutura e Aerodinâmica](https://github.com/orgs/AntaresOrg/teams/estrutura-e-aerodinamica)
